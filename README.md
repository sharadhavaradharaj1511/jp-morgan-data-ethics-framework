# JP Morgan Data Ethics Framework

## Project Type
Academic Project | Baylor University

## Project Overview
Developed a data ethics framework for JP Morgan Chase to evaluate responsible data management, stakeholder impact, compliance, fairness, transparency, and ethical financial operations.

## Tools & Skills Used
- Data Ethics
- Business Analysis
- Financial Services Analysis
- Risk & Compliance
- Regulatory Framework Analysis
- Stakeholder Analysis
- Governance Frameworks

## Key Work Performed
- Evaluated JP Morgan's mission, values, and operational principles
- Assessed stakeholder impact and ethical responsibilities
- Analyzed compliance with GDPR, GLBA, SOX, ECOA, FCRA, and Basel regulations
- Evaluated fairness, accountability, transparency, and privacy principles
- Developed recommendations for responsible and ethical data practices

## My Contribution
Conducted ethics and compliance analysis, evaluated governance principles, assessed stakeholder impact, and developed ethical data management recommendations.
